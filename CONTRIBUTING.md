# Contributing to GoreeCloud VPN

GoreeCloud VPN remains in **Fork-to-Native development** and is not ready for end-user installation.

Create a scoped issue before substantial functional changes, and provide commit IDs, test evidence, compatibility analysis and rollback considerations with networking pull requests. Preserve third-party copyright and license notices. Never commit credentials, keys, private logs or device/network topology.

Upstream NetBird contribution agreements, contacts and support arrangements do not automatically apply to GoreeCloud VPN. NetBird's original documents are preserved for provenance in `docs/upstream/`. Any applicable GoreeCloud contributor agreement must be expressly published by project maintainers.

See [the migration roadmap](docs/fork-to-native/ROADMAP.md).
