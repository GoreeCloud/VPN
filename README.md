# VPN

The [`deploy/netbird/`](deploy/netbird/README.md) folder contains the **fresh-from-zero** NetBird Docker installation, credential bootstrap helper, guarded Caddy and AdGuard routes, an enrollment helper, tests, and security/recovery procedures. The source contains no historic NetBird database, identities, or private keys.

**Live VPS checkpoint (November 20, 2026):** New NetBird combined server and dashboard are running with independent generated credentials and an independent freshly initialized management database and newly enrolled peers. The previous restored deployment containers and runtime directory were removed. Caddy exposes the public NetBird sign-in and returns 404 to public requests for VPN-only AdGuard. First owner login, VPN P2P peer enrollment, and private AdGuard DNS are now verified. The laptop resolves the private hostname over NetBird and reaches AdGuard HTTPS without an IP override, with TLS verified using the Caddy private CA file. The Default all-to-all policy is now **disabled**; the only enabled NetBird access policy permits administrator-device → VPS TCP/443. Post-change laptop HTTPS still works over private DNS while previously working ICMP no longer passes. A private rollback payload is retained on VPS Mesh. Firefox certificate trust and an actual AdGuard account login remain unverified; see the deployment runbook.

## NetBird management CLI

[Source-managed gc-netbird REST administration CLI](tools/netbird-cli/README.md) runs on the authorized VPS and can be invoked from Remote Desktop Commander. It supports peer/group/policy inventory, authenticated REST read/write for groups, policies, DNS and other documented resources, offline --dry-run validation, private output files and dual write confirmations. Local fresh SQLite peer/group/policy inventory works without a token; a private PAT was enrolled and authenticated REST reads and additive group, DNS and policy writes were verified. Future changes still require explicit authorization and CLI confirmation. Never confuse an installed CLI or passing simulated tests with a proven live production policy change.
