# GoreeCloud VPN security reporting

**Development-only foundation. No production deployment or security warranty is claimed.**

Please report potential vulnerabilities privately using GitHub Security Advisories' private reporting feature when enabled. Do not publicly disclose exploits, credentials, private keys, confidential logs, or network topology. If private reporting is unavailable, request a secure disclosure channel from maintainers without posting sensitive details.

Include the exact affected revision and sanitized reproduction evidence. Maintainers should separately triage inherited upstream and GoreeCloud-originated risks. The imported foundation has not yet completed GoreeCloud vulnerability, privacy, or runtime acceptance.
